# Naming status

Date: 2026-09-27

**Phaseweft** is the working name of this GitHub portfolio project. **Crescent Audio** remains provisional metadata inherited from development builds. Neither name is represented as a registered or professionally cleared trademark.

Preliminary web screening did not find a relevant exact-name Phaseweft audio product, but it did find material similarity signals:

- TubeOhm markets an audio plug-in named **Phasewave**.
- **PhaseWeave** is used by an unrelated computing project and in audio-product language.
- **Crescent Audio** is already used by a music/audio presence.

Those findings do not determine infringement or availability. They are sufficient to defer commercial brand freezing.

For the current GitHub objective:

- Use Phaseweft as a provisional project title.
- Do not claim trademark ownership or commercial clearance.
- Keep `MotionFieldState` and parameter IDs independent from the display name.
- Treat any future commercial naming decision as a separate workstream.
