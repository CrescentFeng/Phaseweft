# Asset provenance

Date verified: 2026-09-28

## Demonstration audio

Every WAV file under `artifacts/audio` is procedurally generated by `tests/RenderDemo.cpp`.

The source signal is synthesized in code from sine components, a synthetic click envelope and a generated pad envelope. It contains no recorded sample, sample-library content or third-party music. The dry signal is processed by the repository DSP implementation to produce the four engine examples and six featured-preset examples.

Regeneration:

```bash
cmake -S . -B build/core -DCMAKE_BUILD_TYPE=Release -DMOTION_FIELD_BUILD_PLUGIN=OFF
cmake --build build/core --target motion_field_demo --parallel
./build/core/motion_field_demo artifacts/audio
```

During G1, all 11 retained WAV files were regenerated to a temporary directory and compared byte-for-byte with the repository copies. The comparison passed. During G4, the engine render formerly named `04_motion_field.wav` was renamed to `04_field_matrix.wav` without changing its audio content, matching the current public engine label. Files are 48 kHz, stereo, 16-bit PCM and eight seconds long.

## Signal-flow diagram

`docs/signal-flow.svg` is a repository-authored SVG made from text, paths and geometric primitives. It contains no embedded bitmap, external font file, stock icon or third-party logo. It uses the generic CSS `sans-serif` family.

## Plug-in interface

The plug-in interface is rendered directly by JUCE and the Phaseweft source. No external image, icon or font asset is embedded in the current interface.

`artifacts/screenshots/phaseweft-v0.7-editor.png` is generated by `tests/RenderUISnapshot.cpp`. The tool constructs the current `MotionFieldProcessor`, loads `Utility / Mix Air Motion`, creates the current editor at 1040×650 and writes the component snapshot with JUCE's PNG encoder. It does not read the desktop, another application or an external image.

Regeneration after configuring a plug-in build:

```bash
cmake --build build/release --target motion_field_ui_snapshot --config Release --parallel
./build/release/Source/Plugin/motion_field_ui_snapshot \
  artifacts/screenshots/phaseweft-v0.7-editor.png
```

Two consecutive G4 renders were byte-identical. SHA-256: `4c2838c5d73297239a68eed5231c5fe2332535a71c0584939b033227938d0c12`.

## Publication decision

The retained WAV, PNG and SVG files are project-generated materials and may be published with the repository under the same licence selected for Phaseweft. Any future recorded audio, photography, third-party preset bank, font or visual asset must be added to this document with its source and permission before it is committed.
